# 블럭 왕국 재건 미확정 기획

[확정 기획 위키](game_design.html)에서 옮긴 논의 항목, 후보안, 검증 메모다.

## 제목과 스토리 연출

- 문서와 게임의 제목은 가제 표기로 관리해 왔다.
- 스테이지별 컷신의 내용, 줄 제거와 재건 장면을 연결할 시각 연출, 왕국 복구 후 엔딩을 정한다.

## 스토리 진행과 난이도

- 스토리 목표 시간은 약 7~10분으로 검토 중이다. 기존 기록은 40줄에 2분 초반대다. 40줄을 2분 10초로 가정해 두 배로 환산하면 80줄에 약 4분 20초다. 증강 선택 8회에 회당 10~15초를 더하면 약 5분 40초~6분 20초다. 기믹과 연출을 포함한 새 규칙의 실측값은 없다. 목표 시간에 증강 선택과 연출을 포함할지 정한다.
- 여러 줄을 한 번에 제거해 스테이지 목표를 넘겼을 때 초과분을 유지할지 정한다. 예시 안은 19줄에서 4줄을 지우면 누적 23줄을 유지하고 광장 진입 증강을 보여 주는 것이다.
- 스테이지 전환이나 클리어가 기믹, 증강과 같은 턴에 발생할 때 처리 순서와 이미 생성된 NEXT에 새 난이도 수치를 적용할 시점을 정한다.
- 완화 증강의 효과량과 적용 순서를 정한다.

## 조작과 편의 기능

- T스핀, 세부 입력 편의 기능, 추가 회전 방식은 후순위다. 벽이나 바닥에서 막힌 회전의 위치 보정은 편의 기능 후보이며, 채택 여부와 세부 방식은 미정이다.
- 정식 조작 키와 줄 가져오기 키를 정한다. 일반 게임오버의 정확한 판정과 재도전 시 초기화 범위도 확인 항목이다.

## 전역 증강과 충전재

- 블록 형태별·조합별 추첨 비중, 발동 조건과 능력의 호환 기준, 후보를 생성할 때 정한 조합을 획득 뒤에도 유지할지 정한다.
- 충전재에 더할 능력, 능력과 발동 조건의 유효 조합, 발동 조건의 난도에 따른 효과량과 상한을 정한다. 마을에서 아직 해금되지 않은 기믹에만 의존하는 효과의 취급도 결정한다.
- 설치 효과와 줄 제거의 순서, 홀드한 같은 조각의 반복 발동을 제한할지 정한다. 줄 제거 자체를 발동 조건으로 추가하는 안도 열려 있다.
- 조합형 증강을 만드는 구현 후보로 팩토리 패턴이 논의됐다. 조합 추첨·유효성 확인과 실제 증강 생성의 분리, 클래스 구조와 패턴 적용 여부는 보류했다.

### 이전 전역 효과 후보

| 후보 | 재검토할 사항 |
| --- | --- |
| 블록 낙하 속도 감소 | 지속 시간과 감소량, 설치·완전 파괴·홀드 조건과의 조합 |
| 아래쪽 빈칸 채우기 | 기존 선택 즉시 효과는 블록 동작에 반응해 공극을 채우는 충전재로 발전했다. |
| 특정 블록 출현 비중 증가 | 발동 조건의 블록과 비중을 높일 블록의 관계, 적용 기간과 중첩, 일반 7-bag과의 호환 방식 |

### 성장형 빌드 후보

초반부터 관련 증강을 모아 특정 운영 방식을 강화하는 안이다. 강화 칸은 시계탑, 거대 블록은 궁전에서 해금하므로 미리 고른 증강의 초반 효용과 해금 전후 효과의 연결을 확인한다. 빌드끼리 조합할 수 있는지, 구현량과 채택 범위도 검토한다.

| 빌드 | 성장 방향 | 검토 사항 |
| --- | --- | --- |
| 충전재 | 기본 효과는 발동당 1칸이다. 강화 증강을 얻을 때마다 발동당 1칸을 더 채운다. | 발동 빈도의 성장 방식과 상한, 공극이 없는 높은 지형에서의 효용 |
| 강화 칸 | 강화 칸 대응 수단을 늘리고 처리 보상을 강화한다. | 보상 종류·지급 조건, 강화 해제와 완전 제거의 구분, 다른 증강으로 처리한 경우의 인정 여부 |
| 거대 블록·크러쉬 | 거대 블록이 설치된 칸 일부를 부수며 떨어지는 효과를 강화한다. | 파괴할 칸 수, 충돌 처리, 강화 칸 파괴 여부, 필요한 지형의 훼손, 하강 중에만 적용할지와 성장 방식 |

## 스테이지별 추가 증강 후보

정식 명칭과 세부 효과를 검토할 후보 7종이다. ‘영구’ 효과가 한 판 동안 지속되는지, 재시작 후에도 유지되는지 정한다. 같은 증강의 재등장과 중첩, 효과 상한, 전역 풀의 무작위 조합 방식 적용 여부도 미정이다.

| 추가 시점 | 후보 | 검토 사항 |
| --- | --- | --- |
| 광장 | 도둑 출현 확률 감소 | 단계별 기본 확률의 감소량과 보정 순서 |
| 시계탑 | 강화 칸 내구도 영구 감소 | 감소량과 최솟값, 기존 칸 적용 여부. 내구도 2를 1 낮추면 일반 칸이 되어 강화 효과가 사라질 수 있다. |
| 시계탑 | 강화 확률 감소 | 감소량과 하한, 거대 블록의 강화 추첨에도 적용할지 |
| 궁전 | 거대 블록 출현 확률 감소 | 감소량과 하한, 보정 순서 |
| 궁전 | 특정 거대 블록 영구 제외 | 형태와 지정 방식, 이미 생성된 NEXT나 바구니에 적용하는 시점 |
| 궁전 | 거대 블록과 인접한 강화 블록 제거 | 발동 시점과 인접 범위, 강화 칸만 지울지 조각 전체를 제거할지, 최대 제거 개수 |
| 궁전 | 도둑의 거대 블록 절도 허용 | 온전한 조각 규칙을 적용한다는 후보안이다. 거대 블록 선택 우선권, 대상 범위와 강화 칸 취급을 정한다. |

- 시작 화면에서 설치·완전 파괴·홀드 증강을 하나씩 보장할지, 능력과 조합별 추첨 비중을 정한다.
- 광장·시계탑·궁전 진입 시 3개 후보 중 1개를 새 기믹 대응 증강으로 보장하고 나머지 2개를 전역 또는 기존 해금 풀에서 뽑는 안이 있다. 스테이지 중간에는 해금된 전체 풀에서 뽑는다. 대응 증강이 후보에 나와도 획득 여부는 플레이어가 결정한다.

## 강화 칸과 거대 블록

- 강화 당첨 시 조각의 어느 칸을 고를지와 시계탑 종소리의 재생 시점을 정한다.
- 강화 칸이 남아 같은 줄이 다시 가득 차면 즉시 재판정할지 다음 판정까지 유지할지 정한다. 여러 줄과 여러 강화 칸을 함께 처리하는 순서도 정한다.
- 전체 강화 블록은 초기 테스트 범위에서 빠져 있다. 한 칸 강화의 체감을 확인한 뒤 별도 변형으로 검토할 수 있다. 여러 단계의 내구도를 쓰는 안도 보류했다.
- 거대 블록의 생성 위치, 회전과 미리보기 규칙을 정한다. 회의록에는 오목한 형태와 볼록한 형태의 빈도로 난이도를 조절하는 참고안이 있다.

## 2인 협동과 프로토타입 확인

- 홀드를 공유할지, 후속 모드에서도 시작 시 증강 선택을 제공할지, 공유 난이도와 증강 풀 해금을 어떻게 연결할지, 모드 해금을 어떻게 저장할지 정한다.
- 줄 가져오기 예약 대기 중 추가 충전과 요청을 허용할지, 다른 시점에 받은 여러 묶음을 처리할 순서, 반입 후 완성 줄 재판정을 정한다.
- 증강 선택 중 상대가 보낸 줄을 처리하는 시점, 보드 사이를 옮긴 칸의 블록 소속과 완전 파괴 증강 판정, 증강과 줄 가져오기의 상세 처리 순서를 정한다.
- 현재 프로토타입에서는 시작 화면에서 1인·2인을 직접 고른다. 2인 증강은 시작과 개인 누적 20줄마다 표시하며, 선택 중인 플레이어의 보드만 멈춘다. 한쪽 패배 후 다른 쪽이 계속 플레이하는 프로토타입 동작은 공동 게임오버 규칙에 맞춰 확인한다.
- 프로토타입 조작은 1P가 I/J/K/L, 2P가 넘패드 5/1/2/3 순서로 회전·왼쪽·소프트 드롭·오른쪽 이동을 맡는다. 1P는 왼쪽 Shift 또는 W로 홀드하고 Space 또는 S로 하드 드롭한다. 2P는 방향키 ↑로 홀드하고 ↓로 하드 드롭한다. 증강 선택은 1인 스토리에서 ↑/↓와 Space, 1P에서 I/K와 Space 또는 S, 2P에서 넘패드 5/2와 ↓를 쓴다.

## 검증 메모

확정 수치는 구현과 초기 플레이테스트의 기준이며, 최종 난이도는 플레이테스트에서 확인한다.

- `structured-proto`에서 좌우 이동 중 자동 낙하 시간이 지나면 조각이 일찍 고정된다는 보고가 있었다. 별도 프로젝트인 `tetris-structured/game.cpp`에는 더 내려갈 수 없을 때 즉시 병합하는 경로가 있다. 프로토타입에서 같은 현상이 생기는 원인은 확인하지 않았다.
- `structured-proto`에서 오른쪽 벽에 붙은 조각이 회전하지 못한다는 보고가 있었다. 오른쪽 경계 충돌과 기본 회전 동작을 재현해 확인한다.
- 증강 8회를 받을 때 스테이지별 체감과 시간을 순수 플레이, 선택, 연출로 나눠 측정한다.
- 단계별 독립 추첨과 도둑 예고 처리 턴의 추첨 생략, 실제 도둑 출현 빈도, 강화·거대 밀도와 최고 속도 5칸/초 이후의 장기 난이도를 확인한다.
- 7-bag 하나에 기본 7종이 각 한 번씩 나오고, 거대 블록이 당첨된 바구니는 그중 최대 한 자리만 같은 모양의 거대 조각으로 바꾸는지 확인한다. 실제 출현 빈도가 조각 50개당 1개꼴인지 확인한다.
- 고정 지연 0.5초, 이동·회전 합산 15회 소진 시 고정, 최저 위치 갱신과 재접촉, 실패 입력, 하드 드롭, 오른쪽 벽 회전을 확인한다.
- 줄 가져오기 사용권의 초기 지급, 충전·보유 한도, 빈 보드와 부분 전달 시 사용권 소모, 줄 제거·반출·반입 순서와 동시 설치를 확인한다.
- 공동 게임오버, 개인 20줄 증강, 합산 40줄 난이도, 반출된 줄의 실적 제외를 확인한다.
